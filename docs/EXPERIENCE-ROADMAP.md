# ZNote 体验优化

围绕「采集 → 浏览 → 整理 → 写作 → 找回与迁移」持续优化整个产品。保留知识库隔离、原文件完整恢复、笔记配图分组、来源追溯和现有扩展工作流。

## 已落地：0.9.14 浏览连续性

- 大列表按视口渲染卡片，图片继续懒加载；小列表保留原生网格。
- 每个浏览器分别记住各知识库、各内容分类的搜索、标签组合、排序、布局和浏览位置。默认知识库仍由设置决定。
- 按原浏览图片定位对应分页，支持继续向前、向后加载；已删除或不再符合筛选的定位项回到列表开头。
- 返回窗口时检查更新并提示，不自动重排列表、清空选择或打断笔记编辑。
- 多选支持 Shift 连续选择 / 取消，整组选择仍包含未加载的全部成员。
- 分页请求防重复，切换知识库后丢弃过期响应。

浏览记忆仅存浏览器本地，不含原文件或令牌；最多保留最近 80 个知识库。清除站点数据会清除记忆。跨设备浏览记忆同步、恢复组内上次预览位置尚未实现。

## 已落地：0.9.15 操作撤销

- 普通删除、标签、移动、收藏和已有内容编辑可撤销；操作后提供快捷入口，「最近操作」可在刷新后继续使用。
- 自动记录一起变化的笔记与配图，不复制原文件。撤销只还原相关字段，后续无关修改保留；冲突时整次拒绝，避免部分还原。
- 本次登录最近 24 小时、最多 50 条记录，压缩记录总量上限 32 MB。服务重启保留；重新登录、完整备份恢复后不沿用旧撤销记录。
- 永久删除不可撤销；来源知识库被删除、关联记录被永久删除或引用关系变化时会说明原因。

## 已落地：0.9.16 笔记连续写作

- 本地自动草稿，按库找回未提交笔记；恢复光标与滚动位置，已打开页面可离线继续。
- 多窗口独立草稿与服务器版本冲突保护，正文对照；保存期间继续输入不丢字。
- 每篇最近 50 个、压缩总量 8 MiB 的已保存历史；选用旧版先进入编辑器，普通保存再检查图片与并发版本。历史随完整备份恢复。
- Ctrl / Cmd + S、当前正文 Markdown 导出；本地存储写入失败明确提示并保护关闭。

本地草稿不跨设备、访问地址或浏览器同步，也不包含在服务器备份中。历史版本不保留已永久删除的配图原文件。

## 已落地：0.9.17 常用筛选

- 将当前分类、关键词、多标签及匹配方式、排序和布局保存为命名视图，侧栏一键应用。
- 条件沿用现有列表查询和分组规则，新入库的匹配内容会自动包含；不存固定结果集。
- 按知识库隔离，服务器保存，其他设备可使用；支持改名、替换条件和删除定义。
- 版本冲突保护、切库请求取消、失败重试；定义删除不修改内容。每库至多 50 个，完整备份与恢复保留。

常用筛选同步的是条件；浏览位置和未提交草稿仍按各自的本地存储规则处理。

## 已落地：0.9.18 图片组整理

- 合并、追加与拆分；区分所选图片与整组，确认前预览实际数量、顺序和封面。
- 笔记配图保留原组，共享原文件建立素材引用，或明确跳过；重复采集不覆盖手工整理。
- 整理可撤销，成员和版本冲突整次拒绝；网络响应丢失后用同一回执重试，不重复建组。
- 关联及结果组至多 10000 张，预览至多 60 张；桌面、手机和完整恢复验证。

图片组合并、追加和拆分已完成；拖拽排序撤销在 0.9.21 补齐。新采集的未见页仍按来源组入库，不猜测其应追加到哪个手工组。

## 已落地：0.9.19 大图库连续浏览

- 自动向后续页，可切回手动；失败不反复请求，内容更新时暂停并明确刷新。
- 附近最多 600 项摘要，完整详情按需读取；独立保留最多 10000 项选择，不因缓存回收丢失。
- 续页、缓存替换和向前加载保持可见位置；空闲页尾不持续触发加载，切库取消旧响应。
- 手机结果操作栏不拆散文字；服务 API 默认仍返回完整内容。

自动续页目前向后进行，向前使用加载按钮；浏览位置仍仅在当前浏览器保存。图片/视频组详情内的完整 ID 列表和标签列表仍有进一步优化空间。

## 已落地：0.9.20 跨设备继续看图

- 每库最近 20 个图片组 / 单图的查看位置，含笔记配图；明确的继续查看入口，普通点图行为保留。
- 使用图片 ID，排序后显示当前页码；删除、移动和重新分组的失效记录隐藏，不串库。
- 单请求同步与快速翻页合并，失败请求本地暂存；多设备版本冲突及完整恢复后拒绝旧请求，支持重试或放弃本次同步。
- 完整备份保存记录，清除不删内容，浏览不产生内容事件或额外原文件副本。

服务器同步的是图片查看位置；列表滚动与筛选记忆、草稿仍遵循原有本地存储规则。断网时未同步的记录留在当前浏览器，其他设备只能读取已经同步的位置；这不是视频播放进度同步。

## 后续批次

0.9.21 已补齐排序撤销：预览内直接操作，最近操作可在刷新后找回；完整组顺序与成员检查，原图不复制，笔记正文及封面一起恢复。无关修改保留，连续排序按相反顺序撤销，网络失败重试同一撤销记录不重复执行。

0.9.22 已补齐标签按需浏览：全库搜索、40 个一页、侧栏 30 个、输入推荐至多 8 个；跨页多选、失败重试与切库隔离。用 10000 条内容验证请求及标签 DOM 数量有界。数据库仍按查询聚合当前库标签，超大数据下的聚合索引与缓存可继续测量优化。

0.9.23 已落地统一任务入口：上传与导出移到页面队列，关闭弹窗继续；采集和备份状态集中展示、按库筛选、重试 / 取消及打开结果。上传和导出各自串行；本地活跃及失败任务上限 1000，成功历史 100，分页渲染；统一状态轮询在隐藏页面暂停。尚未实现本地任务跨刷新恢复、断点上传、独立视频预览转码进度和大文件流式导出，后续继续完善。

0.9.24 已落地流式导出：浏览器直接接收下载，服务器按序读取一份原文件，不生成额外 ZIP 副本；任务中心跨页面刷新查看服务器状态、失败重试和取消。原生导出队列至多 20 项，结束记录至多 50 项 / 24 小时。真实 Edge 验证慢速传输期间刷新页面、原文件哈希、手机布局及非安全上下文的局域网 HTTP 下载。服务器重启后记录清空，ZIP 中断后需重新导出，尚不提供 Range 续传。

0.9.25 已落地视频播放位置同步：每库最近 20 个视频、明确继续 / 从头查看、看完状态，播放约每 10 秒及暂停 / 拖动 / 离开时捕获；与图片同步共用已验证的单请求和冲突机制，分开暂存待确认请求。schema 13 增量迁移，完整备份包含视频位置。仅同步已捕获的位置，突然终止浏览器可能丢失最近尚未捕获的进度。

0.9.26 已落地手机连续看图：图片组与笔记配图左右滑动翻页，轻点展开，展开后双指缩放与单指平移；限制拖动边界，横竖屏重新适配，失败原图可重试。使用 Edge 触屏模拟检查手势、编辑保存失败保护及桌面回归，实体 Android / iOS 仍待验收。
