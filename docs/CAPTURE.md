# 多端采集

[返回首页](../README.md)

ZNote 将手机、浏览器和微信收集的内容送到同一个知识库。采集入口负责取得链接或媒体，运行中的服务器负责下载、验证和入库；能识别链接不代表平台一定提供完整资源。知识库顶部「最近下载」可按知识库、时间与状态查看记录，单条重试或重试当前筛选的失败项。[任务与进度](USAGE.md#任务与进度)

## Android

1. 安装 [Release 中的 Android APK](https://github.com/BorderArea01/ZNote/releases)，连接自己的 ZNote 服务。
2. 在采集设置中打开悬浮窗和无障碍采集辅助，启用「复制链接后打开保存面板」。
3. 在原 App 点击「复制链接」。保存面板弹出并填入分享内容后，选择目标知识库，确认保存。
4. 面板收起后继续浏览；完成或失败会反馈，任务记录保留详情和重试入口。

自动弹窗识别明确的「复制链接」操作，不是持续监听任意剪贴板内容。普通复制文字、密码或未提供无障碍事件的按钮不会自动触发。系统权限被关闭、浮窗隐藏或自动弹窗开关关闭时也不会触发；可通过「分享 → ZNote」或浮窗里的读取剪贴板 / 粘贴入口继续保存。

荣耀的「YOYO 建议 → 复制直达」也会在复制网址后显示系统胶囊。ZNote 会短暂等待原 App 返回；面板刚打开就被其他窗口抢走焦点时，在原 App 返回后尝试恢复一次，保留链接与选库，不自动提交。等待有时限，用户关闭或开始操作后不会反复抢前台。如果系统浮层持续遮挡，可在「设置 → 荣耀 AI & YOYO（或智慧助手）→ YOYO 建议 → 复制直达」关闭对应的网址服务；ZNote 不会擅自修改 YOYO 设置。此兼容处理仍需 MagicOS 真机验证。

小浮窗可选择目标知识库、采集当前作品或前往知识库。收起时保留贴边小书签，拖离边缘后恢复完整形态；提交任务后不要求停留在面板等待。

知识库选项优先使用手机缓存，重新打开面板或采集进程后仍可直接选择；在确认保存时才连接并提交采集。点「目标知识库」旁的刷新按钮可更新列表，刷新期间仍能选库和保存，超时或断连会保留旧选项。首次尚无缓存时也可先选未分类。保存失败会保留链接和选择，可在原面板重试；切换服务器或所选知识库已被删除时，会提示刷新或重新选择，不自动改存到未分类。

部分手机限制后台活动。荣耀 MagicOS 可在系统「应用启动管理」中将 ZNote 改为手动管理，允许自启动、关联启动和后台活动；这些开关及无障碍权限需由用户在系统设置中启用。应用内「采集运行诊断」可记录服务退出和响应情况。

## 浏览器

1. 在 ZNote「设置与连接」下载主扩展 ZIP，解压到固定目录。
2. 在 Chrome / Edge 扩展管理页启用开发者模式，加载解压缩的扩展。
3. 同一浏览器打开 ZNote，点击「一键连接扩展」，选择知识库与默认保存方式。

页面边缘工具支持鼠标掠过展开、拖动、触屏点击和贴边收起。入口汇集当前作品、单图、正文、框选 / 可见页面截图及视频嗅探；状态和结果在原页面反馈。可在扩展里禁用当前网站；ZNote 自身自动排除。

更新时覆盖原目录、重新加载扩展并刷新已经打开的网站，保留原连接和偏好。[完整扩展说明](../addons/browser/clipper/README.md)

## 内容与来源

| 来源 | 采集方式与边界 |
| --- | --- |
| Bilibili、百度贴吧、小红书、YouTube、Pixiv | 已有作品分享链接适配；自动弹窗依赖原 App 的复制事件，资源可用性取决于登录、验证和作品本身 |
| 抖音、小红书的图片与实况作品 | 专用解析路径；可取得的实况视频段按视频保存，正文与来源留在备注 |
| 快手、快手极速版 | 识别复制链接/口令事件，支持公开作品页的视频数据解析；平台未提供作品或要求验证时会明确失败，不把站点空页面或封面当视频保存。长视频与受限作品不保证匿名可采集 |
| 百度贴吧 | 按楼主楼层顺序保存配图，正文、作者和出处进入备注，排除其他回复与头像 |
| X | 网页扩展从当前作品读取图片或视频数据；视频需要可用的播放地址，不把封面当视频入库 |
| 图集、公开漫画章节 | 已适配的页面按作品或章节顺序保存；不自动扩展成整站采集 |
| 普通文章 | 提取已加载正文与可归档配图，转为 Markdown 笔记并保留链接 |
| 视频嗅探 | 可用的完整视频或 HLS 资源；预览成功不等于取得完整文件，平台验证与 DRM 不在绕过范围内 |

Pixiv 受限作品可在手机 ZNote 内登录，ugoira 动画目前交给电脑专用扩展处理。YouTube 受限视频依赖账号授权与平台验证，不能承诺任意视频链接均可保存。

有独立配乐时，可将平台提供的音频随作品保存；配乐失败不阻塞主要图片 / 视频入库，可单独重试。图片组预览会尝试自动播放配乐；浏览器阻止时，可手动点击播放，同组翻页不中断，关闭预览停止。

## 局域网与远程

Android 和主浏览器扩展优先使用已配置、已授权且可达的局域网连接；不可达时，可通过已配置的 Cloudflare 备用入口提交作品链接。服务器仍需保持运行并能访问来源平台。

远程收件箱不是完整图库代理，也不承接通用媒体或截图上传。截图、正文附件与原文件上传需要直连；完整图库在外浏览需另配访问通道。[Cloudflare 设置与一键连接](../addons/connectors/cloudflare/README.md)

微信使用独立收件通道，不依赖手机与服务器同网；需主机联网、服务运行且已绑定账号。[微信接入](../addons/connectors/weixin/README.md)
