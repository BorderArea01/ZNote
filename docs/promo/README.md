# ZNote 宣传片：把看见，变成找得到

当前稿约 109.1 秒，13 个场景，高清版本为 1920 × 1080，同时保留 1280 × 720 版本。使用用户选定的「03 手写 Z」，提供温和女声与轻快男声两个神经语音版本，配合程序生成的原创配乐。旁白时配乐自动降低音量；各镜头时长依据实际语音检查并留白。

画面为原创动效和演示数据，属于概念宣传片，不冒充真实操作录屏。平台采集受登录、验证和可用资源影响，宣传内容不能解释为任何链接都保证采集。

## 发布文案

**标题：** 做了个笔记软件，结果发现灵感根本不会等你打开它

**简介：** 微信里聊到的点子、网页上看到的参考图、手机里刷到的作品，总会散在各处。ZNote 把微信收件、浏览器采集和 Android 浮窗接到同一个私人知识库。图片和图组有自己的浏览与整理方式，文字与来源一起留下，需要时用搜索和标签找回。服务运行在自己的电脑或 NAS，内容可以备份、导出，也能通过 API 与可选 AI 学习笔记插件接入自己的流程。

## 维护与重新导出

源码集中在 [tools/promo](../../tools/promo/README.md)，台词与时长以 [storyboard.json](../../tools/promo/storyboard.json) 为准。修改产品介绍时同时核对 README、分镜与成片。成片、语音、音乐、字幕和验证图片写到本地 output/promo-znote，不把媒体缓存与依赖提交到仓库。
