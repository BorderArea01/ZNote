# ZNote 使用指南

这里保留收集、浏览、整理与恢复的完整操作说明。首次安装请先阅读 [快速开始](../README.md#快速开始)。

## 微信收件箱

**出门用微信发送，家中的 ZNote 自动保存。** 手机与运行 ZNote 的电脑无需处于同一个局域网：双方能够连接互联网即可，ZNote 主动从微信服务器收取消息，不需要公网 IP、端口映射或内网穿透。

`手机微信 → 微信服务器 → 运行中的 ZNote → 本地知识库`

### 连接与使用

1. 打开 ZNote **「设置与连接 → 微信收件箱」**，选择默认知识库和标签。
2. 点击 **「扫码连接微信」**，使用个人微信扫码授权；如提示验证码，在页面填写。
3. 向绑定的 **ClawBot 收集会话**发送内容，在「最近收件」中查看入库结果。

| 发到收集入口的内容 | 保存到 ZNote |
| :--- | :--- |
| 文字 | 追加到当天的 Markdown 笔记，保留正文与链接 |
| 图片 | 原文件本地保存，追加到同一篇笔记，并归入该笔记的配图组 |
| 分开发送的文字、图片、说明 | 按接收顺序连续追加，自动添加「微信」及自定义标签 |

默认 **按天合并（北京时间）**，以消息的发送日期分篇。比如先发「今天的设计参考」，再发三张图片，最后发说明，这些内容都会进入同一篇「微信收件 · YYYY-MM-DD」，不会每条消息都新建笔记。

一天内换话题时，可在微信发送 **`/新篇 旅行参考`**，后续消息进入新篇；也可在设置中填写标题并点击「开始新篇」。留空标题使用日期命名，收到内容时才创建笔记。设置还可选择「手动分篇，持续追加」（跨天不自动分篇）或原来的「每条单独保存」。

追加保留已经编辑的标题、正文与封面顺序。设置变化和新篇边界只影响后续收到的消息；旧笔记不自动合并，已排队消息保留原归档目标。一条图片失败时，同篇后续消息等待，重试或忽略后再继续；收件记录优先显示失败项，成功记录可以直接打开内容。

**运行条件**：ZNote 主机保持开机、不休眠、联网，服务运行且开启接收；知识库网页可以关闭。手机使用流量或其他 Wi-Fi 也能投递。断网后自动重试，失败收件可手动重试或忽略；连接过期时需重新扫码。停机期间的消息能否补收，取决于微信平台保留情况，不保证无限期补收。

<details>
<summary>账号要求与当前支持范围</summary>

- 需要微信账号和客户端可使用 ClawBot 通道，由本人扫码确认；实际可用性以绑定后发送测试为准。
- 直接对接通道，无需安装 OpenClaw 或配置 AI 模型；只接收绑定账号向此入口发送的消息，不读取普通好友聊天或历史记录。
- 默认将分开发送的文字与图片连续追加到当天笔记。目前不接收群聊、语音、视频及其他文件消息；单篇最多 50 万字符、30 个标签，超限消息保留在失败记录中。
- 微信可能压缩发送的图片；ZNote 保留实际收到的文件，不会还原微信已经压缩掉的画质。单张图片最多 25 MB。
- 接收队列与连接配置随完整备份迁移；换机器前停用旧实例的接收，避免两台主机共用同一连接。

</details>

**微信投递不等于远程浏览知识库。** 在外直接打开 ZNote 网页，仍需另外配置远程访问；微信入口只负责把发送的内容收进知识库。

详细操作、备份说明与协议依据见 **[微信接入说明](../addons/connectors/weixin/README.md)**。

## 视频接着看

进入 **「视频素材 → 播放记录」**，从上次的位置继续；直接打开视频时，也可选择「继续到…」或「从头查看」。定位后保持暂停，由你决定何时播放。播放时约每 10 秒同步，暂停、拖动、隐藏页面或关闭预览时保存；仅打开预览不会覆盖旧进度。

每个知识库保留最近 20 个视频的位置与看完状态。其他设备登录同一服务可以接着看，多设备冲突时由你决定是否同步本页位置。断网后未确认的请求在当前浏览器暂存，重新打开后可重试；尚未成功同步的位置不会出现在其他设备上。清除记录不删除视频，完整备份包含已同步记录。

## 任务与进度

右上角 **「任务」** 汇总上传、网络采集、导出与备份。上传和导出时可以关闭弹窗继续浏览，任务中心可查看状态、重试失败任务、取消尚未开始的任务或打开已入库内容。任务按知识库筛选，完整备份明确标为全部知识库。

上传仍需保持整个网页打开；刷新后本地文件需重新选择。**导出由浏览器直接接收下载流**，不在网页中暂存整包；下载开始后刷新页面，任务中心仍能找回服务器状态。最终保存位置、进度与取消操作可在浏览器下载列表查看。服务器传送完成不等于确认文件已保存到磁盘。

网络采集、导出和备份由服务器执行。采集与导出记录在服务重启后清空，已保存文件保留；导出至多保留最近 50 条结束记录、最长 24 小时，不额外存储 ZIP 副本。浏览器未开始接收时，任务中心可点击「开始下载」；5 分钟未开始会提示重试。清除本地任务记录不会删除素材或服务器备份。

## 连续批量整理

点击「选择内容」，或按住 **Ctrl / ⌘ 点击卡片**，即可开始多选。卡片正文和勾选框都能切换选择；按住 **Shift 点击**连续选择或取消，**Ctrl / ⌘ A** 选择当前知识库中符合筛选的全部内容，包括尚未滚动加载的部分。输入框与弹窗保留自己的键盘操作。

批量工具栏在滚动时保持可见，可反选已加载内容、改标签、移动、收藏、整理图片组、删除或恢复。整组选中后再次点击即可取消整组；**Esc** 先清除选择，再按一次退出。添加标签后可继续移动或收藏，无需重新选择，支持撤销的操作可从撤销提示或「最近操作」恢复，永久删除除外。

全选支持进度和取消；发生断网、数据变化或超出 10000 项上限时，原有选择保持不变，不会把部分结果误当作全部。切换知识库或筛选条件会清除选择，避免整理范围混淆。

**整组选择**：点击图片组卡片或图片预览里的「选择整组」，一次选中该组全部图片，包含被筛选隐藏和未加载的成员。支持继续加选其他组、取消单张、批量标签、移动、收藏和删除；批量操作最多 10,000 项。完整选中笔记配图后移动，会同时移动所属笔记。

**批量删除**：按标签筛选 →「选择内容」→ 点击卡片、选择整组或「全选筛选结果」→「删除所选」。内容进入当前知识库回收站，可撤销或批量恢复。回收站支持「永久删除」「永久删除所选」和「清空回收站」；永久删除前显示实际范围并确认。清空会处理当前知识库全部回收站内容，不受筛选影响。

**配图与回收站分离**：图片移入回收站时，引用它的笔记自动保留独立配图，原文件去重共享；笔记不会继续引用回收站条目。已有旧引用会自动修复。新引用须先恢复原图片。永久删除仅释放不再被任何条目使用的原文件。删除笔记后，保留的配图仍按原组展示，组名、顺序和首图封面不变。

## 成组浏览与整理

手机看图时，在图片上左右滑动即可翻页，笔记配图也支持。点击展开后，双指缩放、单指拖动，双击放大 / 复位；点击图片外的空白处退出。普通预览保留上下滚动，展开后手势只操作当前图片。电脑继续支持滚轮、A / D 和方向键翻页，展开后用滚轮或 `+` / `−` 缩放、`0` 复位、`Esc` 返回。

缩放范围为 25%–800%，拖动边界和横竖屏切换会保持图片可找回。图片加载失败时可直接重试；正在保存或整理时暂停手势翻页，修改保存失败则留在原图。

标签多时可直接搜索整库作者或关键词，每页展示 40 个标签及使用次数。跨页选择仍保留，可以匹配全部或任意标签；编辑笔记、上传和批量修改标签时，输入关键词也能找到冷门标签。标签加载独立于内容列表，手机筛选栏保持紧凑。

选择图片后点击 **「整理图片组」**，可组成新组、追加到已有组或拆为独立图片。默认只处理选中的图片，勾选「包含所选图片所在的整组」可包含未加载的成员；确认前显示实际范围与封面。追加保留目标封面，整理后可以撤销。

笔记配图可选择跳过，或保留原笔记配图组、共享原文件建立素材引用。手工整理后的分组不会被重复采集打散。网络响应丢失时点击「重试本次操作」，不会重复建组。

图片组预览内点 **「调整顺序」**，拖动缩略图后保存，**排在第一张的图片就是封面**；也可用前后移动按钮或「设为封面」。笔记内点「调整配图顺序」，可选择同步正文图片顺序，文字和图片链接保留。顺序保存在本地数据库，重新打开、迁移和完整备份恢复后仍有效。

排错了可直接点预览底部的 **「撤销排序」**，一起恢复顺序、封面和本次同步的笔记正文。关闭预览或刷新后，也能从「最近操作」撤销。同组后来增删、移动或再次排序时会检查冲突，避免覆盖新整理；不相关的标签、收藏与标题修改保留。

笔记编辑与预览按窗口高度自适应，标题、工具栏与保存栏保持可见；长正文仅在中间区域滚动。

同一篇笔记的配图会在素材库折叠成组；点击正文中的任意图片，按正文顺序连续浏览。预览下方有可点击的缩略图列，也可用 **A / D、← / →** 或在图片上滚动鼠标翻页。**点击图片展开后，滚轮改为缩放**，拖动平移，双击复位。

在图片组预览中修改 **「知识库 · 整组」** 并保存，会移动整组图片；笔记配图组会连同笔记一起移动。目标存在冲突时整次取消。需要单页整理时，使用「选择内容」。配图记录独立管理，相同原图共享文件，不重复占用原图空间。

图片说明支持 Markdown，作者和来源保留可点击链接，原图地址与重复来源不再堆在说明中。筛选、上传和编辑时的标签建议均来自所选知识库。

图片与视频预览随窗口高度自适应，缩略图、翻页和保存操作保留在窗口内。较矮的桌面窗口会收紧留白、并排显示知识库与标签；长说明只在详情区域滚动，不再把整张预览卡片撑出屏幕。手机采用上下布局，保存栏始终可见。

**操作更顺手**：点击弹窗外空白或按 Esc 关闭当前窗口；嵌套预览只退出最上层，笔记先保存本地草稿；写入失败或其他未保存编辑会提示。选择模式下，点击图片、标题、卡片正文或勾选框都能选中 / 取消，键盘和手机触摸同样适用。

## 常用条件，一键找回

**跨设备继续看图**：每个知识库都有「继续查看」和「浏览记录」，保存最近 20 个图片组或单张图片的最后查看位置，笔记配图也支持。另一台设备登录同一个 ZNote 后即可接着看；直接点击图片仍打开你点的那张。

记录按图片 ID 定位，调整顺序后显示新的页码；删除、移动或重新分组后的失效记录会隐藏。记录随完整备份迁移，清除记录不会删除图片。同步失败时可重试；有多设备冲突时，由你选择同步本页位置或放弃本次同步。

大图库滚动接近底部时会自动续页，也可在列表下方关闭 **「滚动自动加载」**。页面只保留附近最多 600 项摘要，远处卡片不挂载；已选内容仍然保留。向前查找可点击「加载前面的内容」，打开笔记或媒体时读取完整详情。

续页保持当前图片的位置。网络失败时点击「重试加载」；有内容更新时先刷新，避免新旧分页混合。当前浏览范围会显示在列表下方，偏好保存在此浏览器。

选好分类、搜索关键词、标签组合、排序和布局后，点击搜索栏右侧的 **「保存当前筛选」**。命名后，它会出现在当前知识库的 **「常用筛选」** 中；下次点击即可重新筛选，新入库的匹配内容也会自动出现。

每个知识库独立保存，支持全部 / 任意标签匹配；手机或其他电脑登录同一个 ZNote 服务也能直接使用。点名称旁的「…」可以改名、替换为当前条件或删除。**删除筛选不会删除图片、视频或笔记**。

## 安心续写

笔记修改会自动保存为**此浏览器的本地草稿**。关闭后再打开，恢复正文、光标和编辑滚动位置；「本地草稿」按知识库找回尚未提交的新笔记。已打开的页面断网后也能继续写作。点击保存或按 **Ctrl / Cmd + S** 才提交到知识库；保存期间继续输入的内容不会被旧响应覆盖。

两个窗口各自保留草稿，服务器版本冲突时不会覆盖较新的笔记。重新打开后可以对照本地草稿再决定继续编辑。右上角可导出当前正文为 Markdown，包含尚未提交的文字；此快捷导出不打包配图。

**版本记录**保留每篇笔记最近 50 个已保存版本，压缩总量至多 8 MiB，并随完整备份迁移。选用旧版本先载入编辑器，确认保存才更新笔记。历史记录不会另存或保留已经永久删除的图片。

本地草稿属于当前浏览器和访问地址，清除站点数据会一并清除；不会跨设备同步，也不包含在服务器完整备份中。

## 浏览器采集

扩展使用独立的石墨灰暗色界面与蓝紫色强调色，覆盖悬停预览、资源浮窗、作品批量入库和连接设置。网页知识库仍可使用你选择的主题。

桌面 **Chrome / Edge** 扩展随项目提供。

### 连接一次，之后直接使用

1. 在 ZNote「设置与连接」下载扩展 ZIP，解压到固定目录。
2. 打开浏览器扩展管理页，启用开发者模式，选择「加载解压缩的扩展」。
3. 在同一个浏览器刷新 ZNote，点击 **「一键连接扩展」**，无需复制地址或 API 令牌。
4. 在扩展设置里选择默认知识库、标签和快捷键。

**网站黑名单**位于扩展设置的「浏览器行为」中：每行一个域名（含子域名）或完整网站地址（区分端口）。命中后停用悬停预览、媒体浮窗和视频嗅探；当前连接的知识库及带有 ZNote 页面标记的网站自动排除。保存后已打开页面同步生效。

**正常更新会保留连接与偏好**：覆盖原目录并重新加载扩展，再刷新目标网页即可。0.7 及更早版本首次升级，需要移除旧版、加载新版，再一键连接一次。

### 图片、视频、正文，一起收藏

| 采集对象 | 操作 |
| :--- | :--- |
| 图片 | 悬停展开大图，直接点击下方 **下载 / 保存知识库**；也可使用默认 `S` / `Z` 快捷键 |
| 预览大小 | 使用大图下方滑杆调节；窗口自动避开正在操作的封面，兼容视频封面悬停播放 |
| 视频资源 | 打开页面右下角「视频」浮窗，专门嗅探 MP4、WebM、MOV 和 m3u8；选择预览、下载或入库，图片使用悬停采集 |
| 网页正文 | 点击「保存页面正文」，提取为可编辑 Markdown，默认将配图一并归档 |
| 网页截图 | 使用扩展弹窗或右键菜单截图当前可见页面 |

网络采集自动保留**来源网址和网站标签**，例如「小红书」「b站」「抖音」「X」。同一文件从多个页面采集，会合并来源，方便回看出处。

**Pixiv / Pawchive**：在单个作品页采集正文。Pixiv 读取全部页的原图和作品说明；Pawchive 从正文文件链接获取原图，排除头像、推荐卡片和缩略图。

**漫画与多图作品**：在 Pixiv 作者 / 推荐页、Pawchive 列表的小封面上，也能展开对应作品并滚轮翻页。预览优先使用网站提供的较轻大图，提前加载相邻页；「查看原图」可切换完整画质。鼠标留在原缩略图或展开预览上都能翻页。点击「批量下载 N 张」按页序保存到 `下载目录/ZNote/作品标题/001.png…`，点击「批量入库 N 张」可选择知识库与多个标签，整组原图带上来源链接、网站标签和页码。下载和入库分别记录进度，始终使用原文件，支持停止、继续、失败重试和刷新恢复。其他网站按当前文章或明确图库中可识别的图片分组，每组最多 200 张。

扩展 **0.9.15** 的批量入库直接在当前网页打开小浮窗，选择知识库与标签后保存，不再跳转新标签页。收起浮窗仍继续处理，可展开查看逐页进度、停止或重试；刷新原网页后通过「查看入库」找回未完成任务，由你手动继续。离开或关闭原网页会中断当前处理，浏览器重启或扩展重新加载会清除临时任务。浮窗只按需加载，不在后台扫描图片。

此前 **0.9.14** 修复了批量入库只记录文字页码、实际没有成组的问题。Paw、普通扩展中的 Pixiv 和通用网页图集都提交作品组与页序，首张作封面；重试不会重复建组，已有手工分组与笔记配图归属保留。相同内容的多页保留各自位置，但共享原文件。更新时覆盖原扩展目录并重新加载，API 连接设置保留。

**其他插件**：专用插件独立维护，不随知识库提供安装包或下载地址。使用插件自身的连接设置填写 ZNote 地址和写入令牌；数据写入、成组和来源追溯遵循 [API 接入规范](API.md)。

**图文笔记的配图默认本地归档**：普通 Markdown 外链图片也会在保存时尝试入库，成功后改为内部地址。已有笔记可点击「归档外部配图」；无法下载时保留来源和失败说明。每次最多 200 张 / 500 MB，单张 25 MB，可再次保存继续处理。

**抖音视频作者**：采集时自动将作者昵称加入标签，支持详情、信息流及带 `modal_id` 的弹层页面。重复保存已有视频可补齐标签，保留手写备注；扩展需更新并刷新原网页。

更多操作、权限和格式支持见 **[扩展使用说明](../addons/browser/clipper/README.md)**。m3u8 合并及平台视频链接解析需要媒体组件，可运行 `npm run media:setup` 安装。

离开原图和预览区域后约 150 毫秒收起；移向按钮时保留穿过间隙的时间。旧版默认 S/K 会改为 S/Z，其他自定义组合保留；需要 K 时可在新版设置中重新指定。

### 单张组与多图组

只有一张图片的组按普通图片显示，不显示组标记和组内选择、排序按钮；无需重新导入，原来源和作品关联保留。后续补入同组图片时自动显示为图片组。搜索、标签或收藏筛选只匹配一张时，不会把原来的多图组当作单张；组成员范围仍限定在当前知识库。
