# 手机 App 与采集浮窗外观提案

用户要求提供几版风格选择，范围只含手机 App 与采集浮窗。本目录是独立、可交互的设计预览，未应用到已发布 APK，不修改网页端主题，也不会提交采集或调用知识库 API。

| 编号 | 方向 | 设计特点 |
| --- | --- | --- |
| A · 纸白 | 留白、平面 | 浅白底、森林绿、细边框、轻量排版 |
| B · 石墨 | 深色、克制 | 石墨底、暖金操作色、紧凑分段标签、清晰层次 |
| C · 雾蓝 | 轻盈、圆润 | 浅雾蓝、圆角卡片、悬浮底栏、柔和面板 |
| D · 暖砂 | 温暖、收藏 | 暖纸底、陶土红、宋体标题、开放式图片排版 |

保持现有手写 Z 图标。各版都可查看 App 首页、采集设置、相册，以及浮窗展开/收起/拖拽贴边、选知识库、粘贴链接、前往知识库和采集状态。所有内容和结果均为演示；选择风格后再实现原生界面，并保留既有采集能力。

预览入口 `index.html`，支持 `?theme=paper|graphite|mist|sand`；`?board=1` 显示四版总览，适合 1920px 视口导出对比图。页面没有第三方字体、脚本或真实用户素材。

本机验收：`scripts/run-resource-guarded.ps1 -Lightweight` 以 128 MiB Node heap 串行运行 `tests/mobile-style-preview.mjs`；`--live` 检查实际发布的公共静态预览。只验证设计预览，不代表 APK 已改版或手机真机已验收。

Cloudflare Pages 构建只复制本目录的三个公开文件到 `/design/mobile-ui/`，不复制配置、采集状态或用户媒体；原收件与邀请接口保留。
