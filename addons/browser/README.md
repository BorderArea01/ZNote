# 浏览器插件

[扩展总入口](../README.md) · [插件维护规范](../../docs/BROWSER-ADDONS.md)

| 目录 | 职责 |
| --- | --- |
| `clipper/` | 可直接在浏览器加载的公开网页采集扩展 |
| `common/` | 多个插件复用的导航、帮助与基础样式，构建时复制到各自安装目录 |
| `catalog.json` | 公开插件登记表 |
| `private/` | 本机其他插件及独立登记表，全部被 Git 忽略 |

从仓库根目录运行 `npm run addons -- list` 查看本机插件；`check` 检查版本、固定 ID 和资源。构建或打包必须指定插件编号，避免误操作其他插件。

插件在浏览器中独立运行与保存连接。公开页面只显示「其他插件」管理入口，不枚举私人插件或提供其下载地址。保持原加载目录更新，随后在浏览器扩展管理中重新加载。
