# ZNote · 网页采集 0.9.37

## X 视频采集（0.9.37）

X 视频不能只传“有视频”的标记后再次让服务器解析受限链接。扩展现在从已打开页面的 React 播放数据或当前页面 GraphQL 响应中，按推文编号读取 MP4 清晰度候选，优先高码率；只传该帖的播放地址，不传 Cookie、请求头或原始响应。服务器直接下载和验证视频，正文保存在说明、保留出处；本机下载使用相同地址。没有读到播放地址时提示在原帖播放后重试，不保存成正文笔记、封面或几百字节的初始化片段。更新后需重新加载扩展并刷新作品页面，让页面读取器生效。

## X 页面采集（0.9.36）

X 公开嵌入接口可能返回 `TweetTombstone`，不代表网页中的推文已删除。单帖按钮、通用工具栏和扩展弹窗现在优先读取已打开页面中编号匹配的推文正文与图片，再由服务器下载原图、成组保存，正文进入备注；同样支持设置中的本机下载方式。排除头像、引用帖和其他帖的媒体，正文截断或媒体未显示时先提示展开。仅粘贴链接且当前页面没有该帖时仍使用公开接口，不能保证登录受限内容可采集。

## 默认保存方式（0.9.35）

在「扩展设置 → 浏览器行为 → 默认保存方式」选择「保存到知识库」或「下载到本机」，并保存。网页图片、套图、视频、整帖、正文和截图只显示所选操作，另一种按钮及快捷键停用；默认入库。X、小红书单帖按钮与右键菜单同步调整。切换会保留原知识库选择，已启动的任务沿用开始时的方式。

下载到浏览器默认下载目录的 `ZNote` 文件夹，不创建知识库条目或服务器采集记录。整帖下载保留全部可读图片与实况视频，跳过实况封面；个别资源失败继续后续资源并显示实际结果。纯正文下载 Markdown 并保留来源与配图链接。平台解析及 m3u8 合并仍需要连接 ZNote；平台未提供视频直链时需播放后使用嗅探，不会改成入库。下载状态按浏览器实际完成/中断判断，见 [Chrome Downloads API](https://developer.chrome.com/docs/extensions/reference/api/downloads)。

## 通用页面工具栏与采集进度（0.9.34）

HTTP(S) 网页共用右下角工具栏，不再只限 X。左侧把手支持鼠标、触屏拖动与方向键微调，位置跨页面记住；窗口变小时自动限制在可见范围。视频面板会跟随工具栏避让。

「⋯」菜单统一提供目标知识库、粘贴作品链接、框选/可见页面截图、页面正文、视频解析、浏览知识库与设置。保留 X 时间线和小红书单帖按钮；黑名单及“常驻媒体浮窗”开关同样控制工具栏。

采集显示服务器实际阶段、已用时间和配图/片段数量，有数量时展示对应进度；未知下载大小不伪造百分比。通用入口复用服务器已有平台解析及公开网页正文采集，不保证登录墙或任意 App 私有数据都可读取。

框选截图先确认页面选择器已挂载，再关闭扩展弹窗；后续选择、保存和反馈不依赖弹窗存活。工具栏、视频面板与预览在截图时隐藏，取消及失败恢复入口可用。Chrome 对截图权限和消息通道的说明见 [Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab) 与 [消息传递](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)。

## X 页面工具栏与提交反馈（0.9.33）

X 详情页的保存本帖、视频入口和采集结果共用右下角一条工具栏，不再叠放三个浮层。提示可关闭或按 Esc 收起，视频面板随提示高度避让；图片预览和其他网站原有入口保留。

提交前核对扩展后台协议，空响应短暂重试一次；后台缺失或旧脚本会明确提示重新加载扩展并刷新页面，服务器错误保留原原因。扩展更新仍覆盖原目录，重新加载后再刷新已打开的网站。

## 入口与插件管理（0.9.32）

弹窗分为「采集 / 任务 / 插件」，顶部选择并记住目标知识库。常用采集直接显示，粘贴链接与平台视频解析按需展开；后台结果、失败重试和取消集中到任务页。右键菜单统一为一个 ZNote 入口，截图与视频分组。

X 详情页右侧固定显示「ZNote · 保存本帖」，无须打开扩展弹窗；时间线含图推文在操作栏显示「保存图组」。支持详情页缺少时间标签、没有操作栏以及 SPA 换帖。插件页可切换图片预览和媒体浮窗，并打开浏览器扩展管理。

各插件的登记、公共 UI、固定 ID 检查和按需打包统一维护，见 [浏览器插件目录](../README.md) 与 [维护说明](../../../docs/BROWSER-ADDONS.md)。

## 整帖图组与大图片策略（0.9.31）

- 扩展弹窗和页面右键新增「框选区域截图」：拖动鼠标或手指选择范围，确认保存；支持重新框选、取消、Esc / Enter，移除选择遮罩后按实际像素裁剪，保存页面来源。
- X 推文的操作栏新增「保存图组」，一次保存本条推文全部原图，按原顺序成组，正文存备注，保留作者、标签与来源；不会混入引用推文的图片。扩展弹窗也可粘贴 X 作品链接。
- 小红书单帖按钮、图组链接入口默认保存图片组与正文备注；弹窗在可用时复用已登录页面的完整作品数据。网页分享采集对 X、小红书采用同样默认值；只有一张图片时保存单图。明确选择「保存页面正文」仍创建图文笔记。
- 在 ZNote「设置与连接 → 采集与文件」选择超过 25 MB 图片的自动策略：保留原图（最多 100 MB）或低损压缩为 WebP。普通扩展默认跟随服务器，也可在连接设置里覆盖。服务器自动压缩不适用于动图或无法达到目标时保留原文件，并在备注说明；PSD 保留图层。
- 单张失败会记录原因并继续后续图片，任务保持可重试，成功项不重复入库。图片读取不再被扩展旧的 25 MB 上限提前拦截。更新覆盖原安装目录后重新加载扩展，并刷新目标网站。
- X 图组使用 X 自身嵌入接口读取公开单帖，接口思路核对 [react-tweet 源码](https://github.com/vercel/react-tweet/blob/main/packages/react-tweet/src/api/fetch-tweet.ts)。平台未提供完整数据时显示失败，不把视频封面当作图组。

## 小红书个人主页收藏卡片（0.9.27）

- 个人主页收藏卡片把 `xsec_token` 放在 `/user/profile/{用户}/{作品}` 链接，而按钮使用 `/explore/{作品}`。扩展现在从同一卡片的这类链接取访问参数，并附到作品地址；已在登录浏览器中确认该地址返回完整作品脚本。
- 服务端支持作品脚本里的空 `new Map([])`，并读取当前使用的 `EF4/EF5` 视频流。旧失败视频任务收到浏览器的新作品数据后直接入队，不再清掉新的视频地址。真实失败作品已重试为 22.334 秒的 AVC 视频。

## 小红书详情状态与卡片参数（0.9.26）

- 同一卡片有多条作品链接时优先使用带访问参数的链接；从详情页打开的作品也能读取当前页面运行时的完整记录，不再只依赖初次加载的 HTML。
- 浏览器和服务器都未拿到完整数据时，提示先打开作品详情再重试，不再建议已经在用扩展的用户重新使用扩展。

## 小红书列表链接补全（0.9.25）

- 列表卡片的链接没有访问参数时，扩展从小红书当前页面的运行时状态中查找该帖对应参数，再以浏览器会话读取完整详情；只接收同一作品编号的结果。

## 小红书单帖已登录采集（0.9.24）

- 帖子列表里的链接只有作品编号、服务器无法独立取得完整数据时，扩展先从当前浏览器已登录的小红书页面提取作品脚本再提交；服务器只保存解析出的采集计划，不保存网页 HTML。
- 此前因缺少作品数据失败的同一任务可由按钮重试，不另建重复图组。网页本身也未加载作品数据或平台要求额外验证时，仍会显示失败原因。

## 小红书瀑布流布局修复（0.9.23）

- 单帖按钮只覆盖卡片表面，不再强制修改帖子卡片的定位属性，保留小红书原有的多列瀑布流排列。

## 小红书网页单帖采集（0.9.22）

- 小红书电脑网页的帖子卡片悬停后显示「保存到 ZNote」，打开帖子详情页也能直接点击该按钮；触屏页面则直接显示卡片按钮。
- 按扩展中保存的目标知识库和标签入库，状态在原网页显示；失败可点按钮重试。同一链接重复点击复用已有任务，不会因连点创建多个图组。网站被加入扩展黑名单后按钮立即消失。

## 按链接采集图组（0.9.21）

- 扩展弹窗新增“按链接采集图组”：粘贴小红书分享链接，或在作品页直接使用当前地址，提交到服务器采集队列并按扩展设置中的默认知识库、标签保存。
- 右键网页中的小红书作品链接可直接选择“按链接采集图组到 ZNote”，不必先打开作品页；弹窗会显示排队、解析和入库结果，并提供已保存条目的入口。
- 该入口复用服务器的图文采集解析，遇到登录、验证或链接已失效时保留失败任务，便于稍后重试；它与“平台视频链接解析”分开，避免把小红书图组误送进视频下载流程。

## 当前网站快速禁用（0.9.20）

- 点击扩展图标即可禁用当前网站的图片悬停预览、视频浮窗和资源嗅探，不必进入设置手动填写域名。
- 禁用状态立即同步到已经打开的网页，并关闭已显示的预览与嗅探面板；再次点击「恢复此网址」即可重新使用。
- 扩展设置中的网站黑名单仍可批量管理；已有更宽泛的规则命中时，弹窗会指向黑名单设置，避免误删其他站点的规则。

## 视频后台处理（0.9.18）

- 视频嗅探列表中的“下载”和“保存知识库”直接在当前网页后台执行，不再打开媒体处理标签页；“预览”仍按需打开独立播放器。
- MP4 与 m3u8 任务使用扩展离屏文档串行处理，切换或继续浏览其他视频不会把新资源混进旧任务，也不会抢走页面焦点。
- 直接 MP4 遇到网页播放器的 HTTP 分段响应时会自动按 `Content-Range` 补齐再下载或入库；Twitter DASH 的 `init.mp4` / `seg-*-init.mp4` 初始化片段会在嗅探阶段过滤，其他只有初始化片段、没有可播放媒体数据的 fMP4 也会被拒绝，不再生成几百字节的假视频条目。
- 当前视频卡片显示排队、下载分片、上传合并和最终结果；切换作品后，浮窗标题区仍保留简短的任务状态。
- 扩展统一命名为“ZNote · 功能名”：公开扩展为“ZNote · 网页采集”，私人站点增强版沿用相同格式。

## Paw 套图快捷操作（0.9.19）

- 悬停网页图片或作者目录封面，主要使用「本图入库」或「整组入库」，不必先把鼠标移进大图预览；套图工具仅保留一个次要的「下载套图」入口。普通悬停预览仍可用 S 下载当前单图。
- 右下角「套图助手」始终可打开；下载与入库进度在当前页显示。标题手柄支持拖拽、方向键移动并记住位置，收起后可随时重新打开。
- 网页内切换下一篇、返回或异步加载配图后，重新识别当前作品；不需要手动刷新页面。识别失败可在面板点击「重新识别」。
- 下载失败可重试未完成项，已完成图片不会重下；真正刷新/关闭网页会中断页面内任务，恢复后手动继续。目标知识库沿用扩展保存的选择，分组与来源信息保持不变。

## 当前网页批量入库

### B 站图文动态

打开 B 站图文动态（`/opus/`，也支持从 `b23.tv` 分享短链跳转）后，可使用「保存页面正文」提取标题、作者、正文、话题和按原顺序排列的配图。手机端把同一分享文字发送给 ZNote 即可走服务器采集，默认保留 B 站来源；视频作品仍沿用视频采集路径。登录限制、仅自己可见的动态或平台验证页面不会伪装成空笔记，任务会保留并提示重试。

点击「批量入库 N 张」直接按上次的目标知识库开始保存，并在网页内显示进度浮窗，无需再点一次保存。需要换库时，在悬停预览的「目标知识库」中选择，后续单图与批量入库沿用该选择。可查看进度、停止与重试；收起后继续保存。刷新原网页会显示「查看入库」，手动继续未完成项。浮窗随内容和窗口大小调整高度。

## 批量入库成组修复

Paw、Pixiv 与通用网页图集批量入库会保存结构化分组及页序，首张为封面。失败重试沿用同一个作品组，相同画面的多页仍分别保留位置，原文件共享存储。旧的未完成批次重新提交时由服务器去重；已手工整理的组与笔记配图归属不覆盖。升级覆盖原目录后重新加载，连接令牌保留。

桌面 Chrome / Edge：悬停看高清图片，浮窗专门嗅探视频。

## 新功能

- 采集入口、悬停预览、资源浮窗、作品批量入库和设置统一采用石墨灰暗色与蓝紫强调色；更新方式不变，固定扩展 ID 保留连接和偏好。
- 小封面根据作品链接或图片标识解析，支持 Pixiv 作者 / 推荐页与 Pawchive 作品列表，只加载当前悬停作品，不混入其他作品。被链接、徽标或遮罩覆盖的封面也可识别，来源保留作品详情页。
- 翻页使用网站提供的较轻预览图（Pixiv regular 大图、Pawchive 缩略图），点击「查看原图」可加载完整画质。仅保留当前页和相邻页缓存；预加载相邻的轻量预览，不批量预下载大体积原图。下载 / 入库和正文归档仍保存原文件；首次加载速度仍取决于源站响应。
- 多图预览显示页码，鼠标留在原缩略图或展开预览上时，滚轮向下 / 向上翻页，也支持左右按钮和方向键。加载期间可继续翻页；移到两者之外后正常滚动网页，输入控件与浏览器缩放不被接管。其他网站按当前文章或明确图库中可识别的图片分组。
- Paw 保留一个次要的「↓ 下载套图」入口，在当前页面板显示进度；主要操作为整组或本图入库。其他网页打开独立进度页并开始下载，按 `ZNote/作品标题/001.png…` 页序保存原图，不重新编码。每组最多 200 张，单张最多 25 MB；依次下载，支持停止、继续及失败重试。保持进度页打开；刷新会保留已完成状态，关闭浏览器后会清除临时进度。无需知识库 API 令牌。
- 点击「批量入库 N 张」，按预览或连接设置中保存的知识库与标签直接开始，并在当前网页浮窗显示进度。整组按页码保存原图，附带作品来源链接、网站标签和原图地址；不会同时下载到电脑。已有批量下载页也可以直接保存到知识库。
- 下载与入库进度独立。入库开始后固定本任务的知识库与标签；停止会等待当前上传确认，重试跳过成功项，同一知识库已有原图会去重。保持原网页打开；离开或关闭会中断，刷新后可手动继续；重启浏览器、重新加载或更新扩展后临时任务清除，需要从原网页重新打开。
- Pixiv 单作品页读取全部页原图、作者与说明；Pawchive 支持 fanbox/patreon 单作品页的正文原始文件链接，排除头像、推荐和缩略图。请先在原网页确认作品可访问。
- 配图默认保存到选定知识库，支持普通、尖括号及引用式 Markdown 图片；浏览器未完成时服务器继续尝试。失败会保留网址并显示原因，可在笔记中继续归档。
- 离开原图和预览区域后约 150 毫秒收起；两者间的通行间隙保留 650 毫秒，方便点击操作栏。指针位于预览图内部时，即使大图为避免遮挡页面而让出鼠标命中，也会保持预览。默认 S 下载、Z 入库；Z 在图组识别或翻页加载期间会等当前图准备完成再入库。旧版 S/K 默认组合随升级迁移，其他自定义组合保留。在新版中重新选择 K 也会按你的选择保存。
- 设置中的辅助说明收进问号图标，支持悬停、键盘聚焦及手机点击。
- 展开的图片下方可以直接点击「下载」或「保存知识库」。鼠标移向按钮时保留预览，停留在操作栏上不会自动收起；保存过程中防止重复点击和切换图片。
- 大图预览内“展示大小”滑杆与连接设置中的最大宽度（240～1200 像素）同步保存。自动寻找当前封面旁的空白区域，避免打断 B 站小视频悬停。单图铺满全屏且没有空白时图片展示层允许鼠标事件穿透；多图作品预览保留鼠标事件以支持滚轮翻页。
- 在弹窗点击“保存页面正文（Markdown）”或使用页面右键菜单，提取当前已加载正文，在独立页修改标题/正文/知识库/标签后保存。保留链接、标题、列表、引用、代码和表格。默认归档正文配图，最多 200 张 / 500 MB；单张 25 MB。未归档图片保留网址并在笔记中说明，不会声称已离线保存。动态折叠内容先在原页面展开。
- 在安装了扩展的浏览器打开并登录 ZNote → 设置与连接 → 一键连接扩展，无需填写地址/令牌。旧版首次升级到固定 ID 时移除旧版、加载新版，再一键连接一次；以后正常更新会保留设置。卸载导致配置清空时同样可一键重连。

## 使用

- 鼠标在图片上停留约 350ms：预览网页提供的最高优先级大图，显示真实像素尺寸。支持原图属性、图片链接、srcset/picture、懒加载和 CSS 背景图；找不到大图时显示当前图，不做放大重编码。
- 大图预览出现时，默认按 **S 下载**到浏览器下载目录，按 **Z 保存知识库**；预览上也有对应按钮。连接设置中的“浏览器行为”可将两个快捷键改成不同的单个字母或数字，保存后已打开网页同步生效。输入框、编辑器和带修饰键的输入不会触发这些快捷键，Esc 收起预览。
- 页面右下角常驻「视频」按钮。打开后只扫描 / 嗅探 MP4、WebM、MOV 和 m3u8；图片继续使用独立的悬停大图下载 / 入库，不进入嗅探列表。每项视频可预览、下载、保存知识库。
- 播放网页视频以发现新的媒体请求。即使播放器 src 是 blob，实际请求的 m3u8 仍可被发现；不会把零散 TS/m4s 分片当作完整视频。
- 浮窗可选择知识库、填写多个标签；可暂停嗅探、清空列表、收起浮窗。连接设置可分别关闭悬停预览或常驻按钮。Alt+Shift+Z 打开扩展弹窗，首要入口是「嗅探本页视频」。
- 原有右键图片/截图、平台视频链接解析继续保留，作为补充功能。

## m3u8 视频

预览使用内置 HLS.js 播放器。下载与入库会读取主播放列表，默认选择最高码率，也可在预览页选择清晰度；支持独立音轨、TS/fMP4、BYTERANGE、普通 AES-128 HLS。完整分片在浏览器取得后交由自己的 ZNote / FFmpeg 合并成 MP4，音视频不重新编码。

合计最多 500 MB、1200 个资源分片；服务端同时处理一个合并请求。保持媒体处理页打开，可取消当前请求。m3u8 下载与合并需要已连接 ZNote；图片/直接视频的下载、预览无需 ZNote 令牌。关闭处理窗口会中断未完成工作。

当前保存完整点播列表，不录制持续直播；不支持 DRM、SAMPLE-AES 或 DASH/MPD 音视频合并。平台视频解析仍可作为部分站点的补充。不是每个网站都提供高清原图或可下载流，签名过期、防盗链及浏览器登录状态策略仍可能导致失败。Chrome/Edge 的内部页、扩展商店及部分内置查看器不允许扩展注入；普通 HTTP(S) 网页默认启用。

## 来源和存储

保存的图片、截图和视频会把来源页面链接写进备注，并保留结构化来源和时间；同库重复文件只补充缺失来源，保留原有备注，不重复存储媒体。按文件下载 m3u8 合并结果不会先写进知识库。

嗅探仅在当前标签页打开浮窗后启动，只观察资源 URL、响应 MIME、大小。悬停作品封面时读取被选中作品的图片列表和轻量预览；选择“保存页面正文”时提取正文。每页最多 100 条嗅探资源，保留最近 12 个标签页，保存在扩展 session 存储。刷新、跳转、SPA 页面变化时清空旧嗅探资源；关闭浏览器后清空，不上传资源清单。批量下载另保留最近 10 个作品任务，最长 24 小时。

用户预览、下载或入库选中资源时，由浏览器按照源站 Cookie 规则携带已有访问状态；扩展不读取 Cookie 值，不读取用户浏览器配置文件，不把 Cookie 或网站会话上传到 ZNote。API 令牌只发给设置的 ZNote 地址，页面脚本拿不到令牌。来源 URL 本身若有分享参数，会按原链接保存在条目中。

## 安装 / 升级

1. 在 ZNote 设置下载 0.8 扩展 ZIP。首次解压，在 Chrome/Edge 扩展管理页启用开发者模式并「加载解压缩的扩展」。
2. 0.7 或更早版本首次升级请移除旧扩展再加载 0.8，避免两个扩展同时显示。之后的更新覆盖原目录再重新加载即可，固定 ID 保留连接与偏好。
3. 在已登录 ZNote 设置点击“一键连接扩展”，随后可在扩展中选择默认知识库和标签；手动填写仍作为可选方式。仅使用悬停、图片/MP4 下载与预览时可不连接。

新增 downloads 用于用户明确触发的浏览器下载；webRequest 用于响应元数据嗅探；webNavigation 用于翻页/SPA 清理。原有 activeTab、contextMenus、storage 和网页 host 权限保留。没有静默后台全站抓取任务。

实现参考：[Chrome webRequest](https://developer.chrome.com/docs/extensions/reference/api/webRequest)、[Chrome downloads](https://developer.chrome.com/docs/extensions/reference/api/downloads)、[猫抓的资源发现思路](https://github.com/xifangczy/cat-catch)。没有复制第三方扩展代码。预览依赖 [HLS.js](https://github.com/video-dev/hls.js) 1.6.15（BSD-2-Clause，许可证随 vendor 文件附带），合并使用已有 FFmpeg。

## 连接复用与来源

新增 `declarativeNetRequestWithHostAccess` 权限仅用于给**本扩展自身向 pximg.net 发出的图片读取请求**设置 Pixiv 来源头，兼容原图防盗链；不改变其他网页的请求，不读取或上传站点 Cookie。其他权限与连接保存方式不变。

旧令牌未被服务器撤销即可继续用。卸载会清空扩展本地设置，重装后在 ZNote 一键重连；更新建议覆盖同一目录再重新加载。服务器只保留令牌哈希，不能取回遗失的明文。验证连接失败不会覆盖原有效设置。详见 [Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage/)。

入库时自动添加来源网站标签（小红书 / b站 / 抖音 / X，其他为域名）；截图、图片、视频一致。保留手工标签，总数上限 30，满额需预留一个位置。相同文件多来源入库合并来源，知识库详情逐条提供可点击来源链接，原始网址也保存在可导出的备注中。

封面检测兼容遮罩层、角标和不接收鼠标事件的 IMG。小红书已知封面预设尝试详情预设，保留签名和当前图回退，不保证每个封面都提供原始分辨率。测试网络访问指定小红书主页受到 IP 风险限制，实际页未通过验收。候选规则参考 [PhotoShow 的封面/详情地址问题记录](https://github.com/Mr-VincentW/PhotoShow/issues/150)。

正文转换基于 [Mozilla Readability](https://github.com/mozilla/readability) 0.6.0（Apache-2.0）和 [Turndown](https://github.com/mixmark-io/turndown) 7.2.4 / turndown-plugin-gfm 1.0.2（MIT）。本地 vendor 附有许可文件，使用 npm run clipper:build 重新生成；不执行远程脚本。固定 ID 参考 [Chrome manifest key](https://developer.chrome.com/docs/extensions/reference/manifest/key)。

## 视频信息与封面

嗅探 MP4 和 m3u8 时尽量读取对应作品的标题、作者及来源；支持常见页面元数据和 B 站、小红书、抖音、X 的作品区域，信息流按视频所在条目区分作者。识别到的作者写入标签（标签最多 40 字）与 Markdown 备注，有主页链接时保留；未识别到作者时不会编造。

视频入库后，ZNote 从本地原视频首帧生成缩略图，包括已有视频。首帧是黑画面时封面也会是黑画面；无法解码时保留播放 / 下载入口。预览不改写原视频，封面只在有上限的内存缓存中保存。

### 抖音作者标签

视频采集会将作者昵称作为一个标签写入知识库，并保留作品和作者主页链接。支持详情页、信息流以及个人页 `modal_id` 弹层；按作品编号或资源 URL 匹配页面数据，避免引用评论用户或导航账号。网页未提供可确认的作者时不猜测。更新扩展后刷新已打开的抖音页面；已存视频可再次保存补齐标签，不重复存原文件、不覆盖手写备注。

视频嗅探现在显示封面、标题与作者；同一抖音作品的多个播放地址合并成一张卡片，可切换线路。作者来自页面作品数据和后续接口响应，保存时自动加入标签。无封面的普通视频仅在悬停或聚焦卡片时按需加载首帧；无法生成时仍可点击播放预览。升级后请刷新已打开的网站，API 连接无需重填。

0.9.13 保留未变化的卡片，合并自动扫描，不再因封面加载反复重建列表；后台标签页暂停扫描，首帧取样一次只运行一个并及时释放视频解码器。
