# Windows 系统右键采集（可选）

独立的小型 Windows 工具，连接现有 ZNote，不需要重装桌面客户端。源码集中在此目录，编译产物和加密连接配置位于被忽略的 `data/windows-capture/`。

运行 `build.ps1` 后，打开生成的 `ZNoteCapture.exe` 配置服务器与 API 密钥并启用菜单。密钥使用 Windows 当前用户 DPAPI 加密；不通过注册表命令或命令行传递密钥。

- 图片文件右键 → **保存到 ZNote**：保留文件原字节，选库后上传。
- 先复制聊天图片，再在桌面或文件夹空白处右键 → **保存剪贴板图片到 ZNote**。
- Windows 11 的传统 Shell 菜单项通常在 **显示更多选项** 中。
- 列表支持缓存和手动刷新，刷新失败可继续使用旧选项；保存失败保留窗口重试。

这只扩展 Windows Shell 菜单；第三方聊天软件自己绘制的右键菜单不会新增此项。剪贴板入口保存的是应用实际复制出来的图片，不能把缩略图还原成原图，也不能保留剪贴板位图中没有的动图帧。

重新连接：`ZNoteCapture.exe --configure`。移除本工具的菜单：`ZNoteCapture.exe --uninstall`。该操作只删除属于当前工具路径的三个菜单注册项，保留配置和已入库文件。
